Capabilities

Built for Real Developers

No compromises. A genuine Debian 13 environment inside your pocket with full package management and seamless phone integration.

Debian 13 (Trixie) Ecosystem

Direct access to the official Debian package mirrors. Install GCC, Clang, Rust, Python, Go, Node.js, Neovim, Git, and tens of thousands of CLI utilities with standard apt.

100% Rootless PRoot Virtualization

Runs entirely in Android userspace using proot syscall emulation. No root privileges needed, zero risk of bricking, and never trips Samsung Knox or corporate MDMs.

First-Time Setup Wizard

Automated initial provisioning creates your custom user account, configures timezone and UTF-8 locales, sets up passwordless sudoers rules, and deploys home directories in one click.

Passwordless sudo & PAM Bridge

Friction-free system administration. Execute sudo apt update or custom service configurations without typing passwords repeatedly, backed by an intelligent rootless PAM bridge.

Android /sdcard Storage Bridge

Direct bidirectional access to your Android internal storage via /sdcard and ~/sdcard. Edit files from Downloads, run scripts from mobile editors, and build directly on phone files.

Coding Keyboard Toolbar

Custom touch row positioned right above your soft keyboard with brackets, pipes, slash, tilde, and modifier keys (Ctrl, Alt, Tab, Esc) with instant toggle between coding and navigation mode.

Multi-Session Terminal Tabs

Run concurrent tasks simultaneously with independent bash sessions. Switch tabs with one tap, with exit dialog safety checks protecting against accidental session loss.

Persistent Background Service

Terminal processes continue running in an Android foreground notification service with active session indicators, preventing OS battery optimization from killing long builds.

Native Kotlin Architecture

Engineered entirely in modern Kotlin with Android Jetpack, coroutines, and clean lifecycle components. Guarantees 60 FPS terminal rendering, zero memory leaks, and optimal battery efficiency.

Standalone signed APK with embedded rootfs unpacker and PRoot binary runtime. Compatible with 64-bit and 32-bit ARM & x86 Android devices.

Download dedroid-signed.apk Installation Guide

Quick Installation Steps:

  1. Download the dedroid-signed.apk package to your Android device.
  2. Open your Downloads folder and tap the APK to install (enable "Install Unknown Apps" in Android settings if prompted).
  3. Launch Dedroid and enter your preferred username and display name in the Setup Wizard.
  4. Tap the folder icon in the top toolbar to grant Android Storage permission for /sdcard access.
  5. Run sudo apt update && sudo apt install <package> to install your favorite tools.
