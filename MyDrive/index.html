Enterprise Grade

Engineered for Complete Sovereignty

No monthly fees. No telemetry. Your files, your server, your rules.

Chunked Streaming Upload Engine

Large multi-gigabyte files are sliced into 4MB binary chunks and streamed directly to disk, preventing RAM spikes and auto-resuming on network drops with zero corruption.

HTTP 206 Media Streaming

Native video & audio streaming with partial content range requests. Scrub or skip through multi-hour 4K movies and podcasts instantly without waiting for full downloads.

Phone Contacts Sync

Sync mobile contacts using the native Web Contact Picker API (navigator.contacts.select). Import/export RFC 6350 vCard (.vcf) and CSV address books seamlessly.

Protected Link Sharing

Share any file or folder with external recipients. Enforce custom passwords, expiration countdowns (1h, 1d, 7d, 30d), and download-only flags with live access tracking.

Mobile & Tablet Ergonomics

Designed with safe-area notch insets, mobile floating action button (FAB), touch gestures, pinch-to-zoom image lightboxes, and 500ms long-press multi-select.

Enterprise Security & RBAC

Argon2id password hashing, realpath canonical path traversal defense (resolve_safe_path), double-submit CSRF protection, and per-user storage quota enforcement.

Quick Terminal Deployment 

# Method A: Docker Compose (Recommended)
git clone https://github.com/dev-hints/mydrive.git
cd mydrive
docker-compose up -d

# Method B: Python Virtualenv
git clone https://github.com/dev-hints/mydrive.git
cd mydrive
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 -m app.main
