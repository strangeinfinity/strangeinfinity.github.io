Sovereignty

Zero-Cloud Data Architecture

How Notes protects your sensitive personal thoughts and records.

No Internet Permission

The app completely omits the Android network permission. Even if malicious code were injected, it physically cannot connect to any server or upload data.

PBKDF2 Key Stretching

Your backup password passes through PBKDF2 with HMAC-SHA256 and 100,000 hashing rounds alongside a 16-byte cryptographically secure random salt.

AES-256-GCM Authenticated

Galois/Counter Mode guarantees both confidentiality and authenticity. Backups cannot be tampered with or modified without triggering decryption verification failure.

Storage Access Framework (SAF)

Notes uses standard Android document pickers to export and import backups. No broad device storage access permissions are requested or required.
