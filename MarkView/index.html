Engineered Precision

Designed for Developers

Every feature is tuned for lightning responsiveness, system efficiency, and deep document insights.

Shiki Syntax Highlighting

VS Code-grade syntax highlighting for 25+ programming languages including Rust, Go, Python, TypeScript, C++, Bash, and SQL with multiple dark and light themes.

KaTeX Math & Formulas

Fast, native KaTeX rendering for inline ($...$) and block ($$...$$) mathematical notation without requiring external network CDNs.

Mermaid Diagram Engine

Render flowcharts, sequence diagrams, class models, state machines, and entity-relationship diagrams directly inside your Markdown documents.

Real-Time Filesystem Watcher

Native Rust debounced monitoring (notify) detects external edits, automatically re-renders changes, and preserves your exact scroll position.

Fuzzy Quick Open (Ctrl+P)

Instant fuzzy search across all files in your workspace, plus global multi-file content regex search (Ctrl+Shift+F) with match previews.

100% Offline-First Security

Zero telemetry, zero remote network calls, and strict AST parsing with rehype-sanitize XSS protection to keep sensitive documentation secure.
